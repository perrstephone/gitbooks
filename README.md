# 🏙️ Welcome to Chicago!

## Important Info

We have two major Categories: Activities and Food.&#x20;

Each category has descriptions, locations, and budgetary information on each thing to do in the city.&#x20;

Rating system: We've done nearly everything on this list, so I recommend everything. However, we add a :star: on the things that Steph highly recommends and a :fire: on the ones that Edwin highly recommends.&#x20;

Location system: Make note of where you are staying and what neighborhoods are nearby. We live and work downtown, so this list has heavy downtown (aka Loop, Streeterville, River North) representation. For more information on the neighborhoods of Chicago, check out this site: [https://www.choosechicago.com/neighborhoods/](https://www.choosechicago.com/neighborhoods/)

Budget system: We've attempted to arrange them based on cost (low to high). We rated them based on what we would consider a full meal for an adult to be. Note: we try to keep these up-to-date, but sometimes prices go up and locations change. If you see a discrepancy, let us know so we can fix!&#x20;

For absolutely everything, we recommend checking the hours yourself. Hours change constantly. It's up to you to make sure it's open when your visit occurs. We've also attempted to note places that are 21+, but you may want to check to be sure about that if you're traveling with children or younger adults.&#x20;

Finally, we have a list of places we still need to check out as well as an Additional Resources page for whatever doesn't fit into the rest of the categories.&#x20;
