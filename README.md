# 🏙️ Welcome to Chicago!

## Important Info

We have two major Categories: Activities and Food.&#x20;

Each category has descriptions, locations, and budgetary information on each thing to do in the city. Finally, we have a list of places we still need to check out as well as an Additional Resources page for whatever doesn't fit into the rest of the categories.&#x20;

### Rating System

We've done nearly everything on this list, so I recommend everything. However, we add a :star: on the things that Steph highly recommends and a :fire: on the ones that Edwin highly recommends.&#x20;

### Location System

Make note of where you are staying and what neighborhoods are nearby. We live and work downtown, so this list has heavy downtown (aka Loop, Streeterville, River North) representation. For more information on the neighborhoods of Chicago, check out this site: [https://www.choosechicago.com/neighborhoods/](https://www.choosechicago.com/neighborhoods/)

### Budget System

We've attempted to arrange them based on cost (low to high). We rated them based on what we would consider a full meal for an adult to be. Note: we try to keep these up-to-date, but sometimes prices go up and locations change. If you see a discrepancy, let us know so we can fix!&#x20;

### Rewards System

Many restaurants have rewards programs! We have an organized directory (and referral link bonus information!) in the Misc area. We make note of if a restaurant is in a rewards system and link you accordingly.
