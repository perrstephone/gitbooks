# 🏙 Welcome!

## How to Use

We have three major Categories: Activities, Food, and Seasonal.

Each category has information, neighborhood, and budgetary information on each thing to do in the city.&#x20;

Rating system: I've done nearly everything on this list, so I recommend everything. However, I add a little star on the things that I \*highly\* recommend.&#x20;

Budget system: I've attempted to arrange them based on cost (low to high). I rated them based on what I would consider a full meal for an adult to be. Note: I try to keep these up-to-date, but sometimes prices go up and locations change. If you see a discrepancy, let me know so I can fix!&#x20;

For absolutely everything, I recommend checking the hours yourself. Hours change constantly, so I won't update it. It's up to you to make sure it's open when your visit occurs. I've also attempted to note places that are 21+, but you may want to check to be sure about that if you're traveling with children or younger adults.&#x20;

Finally, I have a list of places I still need to check out as well as an Additional Resources page for whatever doesn't fit into the rest of the categories.&#x20;
